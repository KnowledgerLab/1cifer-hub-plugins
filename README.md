# 1Cifer Plugins (official)

Официальный реестр плагинов для **1Cifer Hub** — десктоп-приложения [1Cifer](https://1cifer.kz), ИИ-агента для бизнеса. Публикуется командой 1Cifer.

Плагины отсюда — санкционированные и поддерживаемые. Пакеты по архитектурам лежат в GitHub Releases;
индекс `registry.json` генерируется скриптом из релизов (`scripts/regen-registry.mjs`).
